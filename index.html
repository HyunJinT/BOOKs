브라우저 로컬 저장소 사용 중

브라우저 데이터를 삭제하거나 PC를 교체하면 로컬 기록이 사라질 수 있어요. 클라우드를 연결하기 전에는 주기적으로 백업해 주세요.

무료 Firebase 클라우드 연결

GitHub Pages 배포 후 Firebase 프로젝트를 만들면 Google 계정으로 로그인하여 책과 기록을 동기화할 수 있어요. 연결 전에도 앱은 로컬에서 사용 가능합니다.

Firebase 콘솔의 웹 앱 구성 객체를 붙여넣으세요. 웹 설정 값은 공개될 수 있으므로 반드시 Firestore 보안 규칙으로 보호해야 합니다.
미연결 · 지금 저장하는 내용은 이 PC에만 보관됩니다. GitHub Pages에 배포한 뒤 Firebase 연결을 진행하세요.

연결 시 꼭 확인할 것

① Firebase Authentication의 Google 로그인을 활성화하고 GitHub Pages 도메인을 승인합니다.
② Cloud Firestore를 만들고 제공된 보안 규칙에 본인의 UID를 등록합니다.
③ Google 로그인으로 연결하면 기존 로컬 기록과 서버 기록을 최신 수정 시각 기준으로 합칩니다.
